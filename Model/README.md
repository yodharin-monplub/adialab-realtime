# Model Index

Experiments use monotonically increasing directories named `model<N>` without
zero padding. Never renumber an existing model: imports, manifests, notebooks,
and downstream experiments may contain its path.

- `model1/`: pretrained core/candidate baseline and exact historical source.
- `model2/`: train-from-scratch ensemble and exact historical source.
- `model3/`: feature-selected ensemble and exact historical source.
- `model4/`: all-detector screening and nested feature selection.
- `model5/`: uncertainty-aware TSAUC detector selection.
- `model6/`: tuned multi-model ensemble and current submission baseline.
- `model7/`: repeated detector ranking and ensemble stability study.
- `model8/`: additional detector-family screening.
- `model9/`: full-row scaling and exploratory pairwise stacking.
- `model10/`: conditionally nested causal postprocessing on frozen Model 6 and
  exploratory Model 9 OOF predictions; it never materializes or scores
  outer-holdout labels.
- `model11/`: compact causal multiscale features and pair-weighted LightGBM.
- `model12/`: ExtraTrees diversity model on the same compact features.
- `model13/`: boosting with a same-time pairwise logistic objective.
- `model14/`: exploratory pairwise stack with regularized elapsed-time weights.
- `model15/`: conservative feature-dependent correction to Model 9's margin.
- `model16/`: post-hoc blend of Model 10's persistence diagnostic and Model 11.

Models 11–16 use `models/run_next_models.py` (11–13) and
`models/model<N>/run_model<N>.py` (14–16).
Consolidated results are generated by
`models/report_next_models.py` into `NEXT_RESULTS.md`. Every numbered model now
includes the requested `readme.txt`. New source copies are maintained with
`python3 models/snapshot_compact_models.py sync` / `check`; this narrower tool
works with the incomplete historical workspace copy and preserves old snapshots.

Every numbered model has a generated `source/` snapshot. Models 1–3
copy their frozen historical submission implementations; Models 4 onward use a
mini-repository layout containing shared pipelines, every imported detector,
tests, and their upstream model packages. Validate or refresh these copies with
`python3 models/sync_model_sources.py check` or `sync`. Source snapshots exclude
training data, caches, fitted weights, predictions, and logs.

For new models, create `models/model<N>/` with a `README.md`, `readme.txt`,
`__init__.py`, configuration, pipeline, runner, notebook when useful, and an
ignored `runs/` directory. Record upstream model and cache dependencies in the
README. Keep reusable functionality canonical in root modules, then run the
source sync so the model folder also carries an auditable physical copy.

`artifacts/` contains shared feature caches and must remain at its current path:
cache manifests and model contracts rely on stable relative names.
`past_solutions/` contains research from the earlier ADIA Lab competition.
`JOINT_LIGHTGBM.md` and `joint_lightgbm_results.md` document the rejected joint
LightGBM study. Generated artifacts are not submission source code.
